# LMD-6

New programming language LMD-6 inspired by C++, implemented fully in Java.

This project was developed for the Language Processors course, belonging to the Computer Engineering degree at Universidad Complutense de Madrid (UCM). 

It consists of the implementation of a completely new language, LMD-6, including token-based parsing, strict type checking, and the management of functions and expressions via an Abstract Syntax Tree (AST).
The compiler uses WebAssembly to transform the code from our language LMD-6 into a binary format, allowing it to be executed like any other language. The language supports advanced features such as pointer manipulation, static structures (classes and structs), array indexing, and a wide variety of arithmetic and logic expressions.

This project was developed in collaboration with Sergio Martínez Olivera (https://github.com/sergiio8).
